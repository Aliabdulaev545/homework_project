# Homework Project — Анализ транзакций

Приложение для анализа транзакций из Excel-файла. Генерирует JSON-данные для веб-страниц, формирует отчёты и предоставляет сервисы поиска.

## 📋 Функционал

### Веб-страницы
- **Главная** — приветствие, информация по картам, топ-5 транзакций, курсы валют, цены акций.

### Сервисы
- **Простой поиск** — поиск транзакций по подстроке в описании или категории.
- **Поиск по телефонным номерам** — поиск транзакций с мобильными номерами.
- **Поиск переводов физлицам** — поиск переводов с именем и первой буквой фамилии.

### Отчёты
- **Траты по дням недели** — средние траты по дням недели за последние 3 месяца.
